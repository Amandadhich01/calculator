## 🌟 Key Modes & Capabilities

### 1. 🧮 Standard Calculator
- Instant arithmetic with addition, subtraction, multiplication, division, percentage, sign toggle, and parentheses.
- Dual display screen showing the full mathematical expression alongside the computed result.
- Memory registers: `MC` (Clear), `MR` (Recall), `M+` (Add), `M-` (Subtract), and `MS` (Store).

### 2. 🔬 Scientific Calculator
- **Trigonometry**: $\sin$, $\cos$, $\tan$, $\sin^{-1}$, $\cos^{-1}$, $\tan^{-1}$.
- **Angle Modes**: Toggle easily between **DEG** (degrees) and **RAD** (radians).
- **Logarithms & Powers**: $\log_{10}$, $\ln$, $x^2$, $x^3$, $x^y$, $10^x$, $e^x$.
- **Roots & Constants**: $\sqrt{x}$, $\sqrt[3]{x}$, $\pi$, $e$, $\text{random}$, $|x|$, $1/x$, and factorial $n!$.

### 3. 📏 Smart Unit Converter
Real-time, bidirectional conversions across 6 categories:
- **Length**: Meters, Kilometers, Centimeters, Millimeters, Miles, Yards, Feet, Inches.
- **Weight / Mass**: Kilograms, Grams, Milligrams, Pounds, Ounces.
- **Temperature**: Celsius (°C), Fahrenheit (°F), Kelvin (K).
- **Digital Storage**: Bytes, KB, MB, GB, TB.
- **Speed**: km/h, mph, m/s, knots.
- **Time**: Seconds, Minutes, Hours, Days, Weeks.

### 4. 💼 Financial & Commerce Tools
- **Loan EMI Calculator**: Compute exact Monthly EMI, Total Interest Payable, and Total Repayment based on principal, annual rate %, and tenure.
- **GST / Tax Calculator**: Calculate net amount, tax amount, and gross total with custom tax rates (5%, 12%, 18%, 28%).
- **Discount Calculator**: Calculate net savings and final discounted purchase prices.

### 5. ⚡ Smart Experience Features
- **Calculation History Tape**: Records past calculations with timestamps; click any historical calculation to reload it onto the screen.
- **Haptic Audio Feedback**: Realistic soft mechanical key clicks generated in real-time via Web Audio API.
- **Full Keyboard Support**: Type with numpad, digits, Enter, Escape, Backspace, and mathematical operators.
- **Theme Engine**: Toggle between Modern Deep OLED Dark Mode and Crisp Light Mode.

## 🖥️ Running Locally

### Option A: Open in Browser
Double-click `index.html` in any web browser, or serve with:
```bash
python -m http.server 3000
```
Open `http://localhost:3000`.

### Option B: Run Python Tkinter Desktop GUI
```bash
python aman.py
```
