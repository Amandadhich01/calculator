# Calculator

A clean, responsive web calculator with Standard, Scientific, and Unit Conversion modes, along with a desktop version built using Python Tkinter.

### Live Demo
You can try the web version live here:  
**https://amandadhich01.github.io/calculator/**

---

## Overview

This project contains two versions:
1. **Web App (`index.html`)**: A fast, responsive calculator running directly in the browser via GitHub Pages.
2. **Desktop App (`aman.py`)**: A desktop GUI calculator built using Python and Tkinter.

---

## Features

### Web Calculator
- **Standard Mode:** Basic arithmetic (+, -, ×, ÷), percentages, parentheses, and sign toggle (±).
- **Scientific Mode:** Trigonometry (sin, cos, tan, inverse), DEG/RAD switch, powers, square roots, factorials, logarithms (log, ln), and constants (π, e).
- **Unit Converter:** Quick conversions for Length, Weight, Temperature, Digital Data, Speed, and Time.
- **Calculation History:** Stores recent calculations with timestamps.
- **Keyboard Support:** Full keyboard and numpad support (Enter to evaluate, Backspace to delete, Esc to clear).
- **Theme Toggle:** Switch between dark and light modes.

### Python Desktop App (`aman.py`)
- Desktop GUI window built with Tkinter.
- Supports basic arithmetic, trigonometry, square root, powers, factorials, and constants.
- Key bindings for quick input.

---

## How to Run

### 1. Web Version
Open `index.html` in any web browser, or visit the [GitHub Pages live link](https://amandadhich01.github.io/calculator/).

### 2. Desktop Version (Python)
Run the script from your terminal:
```bash
python aman.py
```
